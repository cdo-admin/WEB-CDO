Edit Website

Klik teks, gambar, tombol, atau kartu di halaman di bawah, lalu ubah lewat panel di kanan.

Editor visual hanya berfungsi bila website sudah di-hosting (bukan dibuka dari file di komputer). Lihat PANDUAN_ADMIN.md bagian "Upload website".
Mode edit aktif. Tombol dan link tidak akan berpindah halaman.
Cara pakai
  • Klik teks untuk mengubah kata-katanya (isi versi Indonesia dan English).
  • Klik gambar untuk mengganti foto.
  • Klik tombol / link untuk mengubah tujuannya (WhatsApp, Instagram, LinkedIn, dll).
  • Klik kartu produk / proyek lalu pilih Duplikat atau Sembunyikan.
  • Kartu dengan garis hijau adalah kartu tambahan buatan Anda.
  • Perubahan langsung tersimpan dan tampil di website.

Produk di Form Penawaran

Atur produk, ukuran, dan sub pilihan (misal WG / HP / UHP) yang bisa dipesan pengunjung.

Format baris: tulis satu pilihan per baris. Contoh: Tabung 6m³. Jika tulisan di dropdown ingin berbeda dengan nilai yang dikirim: nilai | tulisan, contoh HP | HP (High Purity).

Pilihan Kustom otomatis selalu ada di akhir daftar ukuran. Kosongkan daftar ukuran jika produk hanya boleh Kustom.

Lowongan Karir

Tambah, ubah, sembunyikan, atau hapus lowongan. Halaman Karir di website langsung mengikuti daftar ini.

Galeri Gambar

Semua gambar di website, dikumpulkan dari seluruh halaman. Klik Ganti lalu pilih foto dari komputer. Foto otomatis dikecilkan, dan langsung tampil di website tanpa Commit / Push.

Hanya berguna bila ingin membedakan beberapa promo di tempat yang sama.

2. Salin link untuk tempat yang Anda pakai

Instagram, WhatsApp, dan TikTok sering menyembunyikan asal pengunjung. Karena itu pasang link khusus di atas, bukan link biasa. Link yang lama tetap berfungsi, hanya saja tidak tercatat dari mana asalnya.

Bantuan

Mengubah teks: Menu Edit Website → pilih halaman → klik teks → ubah kolom Indonesia dan English → Simpan.

Mengganti foto: klik gambar → Unggah gambar. Gunakan foto JPG/PNG/WebP di bawah 2 MB agar website tetap cepat.

Ganti nomor WhatsApp / link sosial media: klik ikon atau tombolnya → ubah kolom Link. Format WhatsApp: https://wa.me/628123456789. Teks nomor yang tampil diubah dengan mengklik tulisannya.

Menambah produk / proyek: klik kartu yang mirip → Duplikat kartu → klik teks dan foto kartu baru untuk mengubahnya. Centang opsi form penawaran agar produk bisa dipesan.

Menyembunyikan produk: klik kartu → Sembunyikan. Kartu tampak pudar di editor, tidak tampil di website, dan bisa ditampilkan lagi.

Kembali ke aslinya: klik bagian yang diubah → tombol "Kembalikan ke asli".

Kunjungan Anda sendiri tidak dihitung di statistik pada browser ini setelah Anda login.

Catatan: perubahan hanya mengganti isi yang ada di halaman. Kalau struktur halaman diubah developer, buka lagi halaman terkait untuk memeriksanya.
